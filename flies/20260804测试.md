先把容器关了：docker compose -f docker-compose.online.yml down
开开：docker compose -f docker-compose.online.yml up

正确流程只有两个接口。

## 1. 跨机台标定

```http
POST http://127.0.0.1:8088/api/v1/agv/cross_calibration
Content-Type: application/json
```

Apifox请求体：

```json
{
  "sn": "station_001",
  "data": {
    "stationId": "station_001",
    "imagePath": "D:/code/AGV/pkg5_260728/outputs/stations/station_001/reference.png"
  }
}
```

调用后，接口会自动完成：

```text
相机拍照
→ 保存到reference.png
→ Aruco检测
→ cornerSubPix
→ 返回跨机台基准
```

必须完整保存响应中的 `data`，特别是：

```text
data.markers
data.markerLengthM
data.preferredOriginId
```

发送前，把上面整个 `reference` 对象替换成跨机台接口返回的真实 `data`，不能保留示例零值或空的 `markers`。

这个接口会自动执行：

```text
相机拍当前图
→ 保存到current.png
→ Aruco检测
→ cornerSubPix
→ solvePnP + solvePnPRefineLM
→ gTc变换
→ 与reference比较
→ 返回六自由度补偿
```

最终正确调用顺序是：

```text
第一次建立机台基准：
/cross_calibration

每次在线二次补偿：
/secondary_compensation
```

不需要额外调用 `/photo`。
