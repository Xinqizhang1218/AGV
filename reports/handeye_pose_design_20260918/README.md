# 四尺寸手眼标定点位设计（2026-09-18）

## 结论

- 原30点方案数量不少，但 RX/RY 多数只有 2–4°、Z 总跨度只有 10 mm，三维激励不足。
- 新方案为每块板各 50 点：41个求解点、5个独立留出验证点、4个重复性检查点。
- RX、RY覆盖 ±6°/±9°，包含四象限复合倾斜；Z覆盖 ±20 mm。
- 大倾角使用由现有图片拟合出的 XY 反向平移回中，不再原地倾斜顶框。
- 预计完整白边最小边距：4/5/6/7 cm分别为162.5/111.8/100.6/107.9 px。
- 以上边距是图像模型估计，不代表机械臂关节、线缆或碰撞安全；首次必须低速单步运行。

## 点位分组

- P01–P41：正式求解集。
- P42–P45：四方向边界留出集，不参与首次求解。
- P46–P49：重复性检查集，不参与求解。
- P50：独立混合姿态留出验证，不参与求解。

P42–P45标记为 `BOUNDARY_CHECK` 时，必须低速运行并实时看图；完整白边不足100 px立即停止，沿回中心方向退2–3 mm后重拍。

## 现场拍摄要求

1. 四块板保持相同P01、相机高度、镜头焦距、对焦、曝光和法兰朝向。
2. 每次都从P01绝对位姿运动，表内增量不能累计。
3. 每个正式求解点要求16/16个ChArUco内角点和12/12个marker完整识别。
4. 任何贴边、裁切、运动模糊、反光或曝光变化都应重拍；不能只按代码最低5角点放行。
5. 先运行P01–P41，确认机械臂和图像安全后，再拍P42–P50。
6. 大倾角点含约30–50 mm的XY回中补偿，这是有意设计，不要删除。

## 求解与验收

- 相机内参分别使用全部求解点和两个独立子集计算：焦距差应小于1%，主点差应小于20 px。
- 手眼固定板平移RMSE：目标≤1.0 mm；1.0–1.5 mm为有条件使用；>1.5 mm建议重拍。
- 固定板旋转RMSE：目标≤0.3°；0.3–0.4°为有条件使用；>0.4°建议重拍。
- 留出点最大三维平移误差应≤3 mm。
- 删除任一求解帧后，gTc平移变化应≤1 mm、旋转变化应≤0.2°。
- P46–P49重复姿态若明显漂移，先排查相机/板安装、机器人重复性和图像—位姿同步，不要继续增加标定点。

## 修正后的4 cm旧数据基线

此前把有效30 mm图案误按40 mm图案计算。按正确的6 mm格长、4 mm marker重算后：

- 有效图片：29/30，旧P13排除；
- 平移RMSE：1.579 mm；
- 旋转RMSE：0.505°；
- 最大单点平移误差：2.586 mm；
- 相机重投影RMS：0.072 px。

旧数据仍未达到上述正式验收目标，但已证明正确板尺寸能显著降低误差；新50点方案重点补足多轴旋转和深度覆盖。
